title: Postgres 인덱스가 안 타는 이유
date: 2026-08-09
category: Backend
tags: [Postgres, SQL]
summary: EXPLAIN ANALYZE를 읽는 법부터 시작해 실제로 겪은 다섯 가지 케이스
---

인덱스를 만들었는데 `Seq Scan`이 뜬다면 대개 아래 중 하나다.

- 컬럼에 함수를 씌웠다 (`WHERE lower(email) = ...`)
- 타입이 암묵적으로 변환된다 (`bigint` 컬럼에 문자열 비교)
- 선택도가 낮아 플래너가 순차 스캔을 더 싸게 봤다
- 통계가 낡았다 (`ANALYZE` 필요)
- `OR` 조건이 인덱스를 쪼갠다

```sql
EXPLAIN ANALYZE
SELECT * FROM users WHERE lower(email) = 'a@b.com';
```

함수 인덱스를 만들거나 쿼리에서 함수를 걷어내면 해결된다.
